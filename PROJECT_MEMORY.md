# AUDIO FORGE Project Memory

- AUDIO FORGE is an AI-first factory for commercial synths, samplers, romplers, MPC/drum instruments, effects, MIDI/generative and audiovisual plugins.
- V1→V3 is one end-state architecture with progressive gates.
- Generated products remain real exportable source-controlled projects.
- JUCE is initial first-class backend; architecture is adapter-based.
- VST3/AU/standalone first; CLAP/AUv3 where appropriate; AAX optional adapter subject to requirements.
- UI must be deeply customizable including skins, arbitrary assets, animation, video and audio-reactive visuals.
- Builder licensing and generated-plugin licensing are independent systems.
- Release factory owns build/version/test/install/sign/notarize/update evidence pipelines.
- ØMEGA is preferred native intelligence/runtime; model roles remain configurable/agnostic.
- XIO and SONARA can invoke AUDIO FORGE through API/CLI/MCP.
- Realtime audio safety and deterministic DSP/host testing outrank AI self-assessment.
- XYRA Audio Gauntlet governs releases.
